# Chandru S - 3D Portfolio Website

A professional, immersive 3D portfolio website for Chandru S, a Microsoft PL-300 Certified Power BI Developer & Data Analyst.

## 🚀 Quick Start (3 Steps)

### Option 1: Run Locally

```bash
# 1. Clone or download this folder
# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# Open http://localhost:5173 in your browser
```

### Option 2: Deploy to GitHub Pages

```bash
# 1. Install dependencies
npm install

# 2. Build for production
npm run build

# 3. Deploy to GitHub Pages
npm run deploy
```

## 🛠️ Tech Stack

- React 18 + TypeScript
- Vite (build tool)
- Tailwind CSS 3.4
- Framer Motion (animations)
- Lucide React (icons)
- Kanit Google Font (weights 300-900)

## 📱 Responsive

Mobile-first design with fluid typography using `clamp()`. Works on all devices from mobile to ultra-wide screens.
